# YourPathUkma — опис проєкту

## Ідея проєкту

**YourPathUkma** — вебплатформа для студентів Факультету інформатики НаУКМА (з можливістю розширення на інші факультети), яка допомагає будувати індивідуальний навчальний план на кожен рік навчання: обирати вибіркові (зазвичай профорієнтовні) дисципліни, розподіляти навантаження за триместрами, стежити за виконанням кредитного навантаження освітньої програми (240 кредитів за 4 роки) і отримувати персоналізовані AI-рекомендації дисциплін на основі обраних напрямків розвитку. Нормативні дисципліни повністю визначає деканат і в конструкторі плану вони не обираються.

Студент заходить на сайт через корпоративну пошту.

## Ролі користувачів

| Роль | Можливості |
|---|---|
| **Студент** | Вхід через SSO; перегляд особистого кабінету та попередніх планів; завантаження документа деканату; налаштування побажань (напрямки, навантаження, викладачі, сертифікат); генерація, збереження та порівняння планів; отримання AI-рекомендацій |
| **Адміністратор** | Запуск парсингу каталогу дисциплін із САЗ; керування довідниками (напрямки розвитку, сертифікатні програми) |

> Деканат є **зовнішнім актором**: надає документ із нормативними дисциплінами та затверджує індивідуальний план у САЗ. Безпосередньо з платформою не взаємодіє.

## Ключові функції

1. **Особистий кабінет** — лічильники кредитів (`використано/240` загальних, `…/25` вільного вибору, `…/54` профорієнтовних), усі індивідуальні плани за роками навчання, кнопка «Оновити» для автосинхронізації затвердженого плану з САЗ.
2. **Конструктор плану** — вибір вибіркових дисциплін по триместрах із вибором рівня навантаження (низьке / середнє / високе) на кожен триместр; перевірка конфліктів із нормативними дисциплінами з документа деканату.
3. **AI-генерація плану** — LLM будує повний план вибіркових дисциплін на основі напрямків розвитку, побажань студента та його власної історії планів; генерує 2–3 альтернативні варіанти на кожен слот; до кожної дисципліни — коротке пояснення, чому вона корисна.
4. **Каталог дисциплін із фільтрацією** — дисципліни надходять із САЗ через парсинг, що запускає адміністратор; фільтрація за напрямком, триместром, викладачем, кредитами, роком; автоматичний контроль ліміту 25 кредитів вільного вибору.
5. **Підтримка сертифікатних програм** — парсинг сайту факультету із сертифікатними програмами, звірка переліку дисциплін із каталогом САЗ без урахування регістру; пропозиція сертифікатних дисциплін або повідомлення: «ця дисципліна входить у сертифікат Х».
6. **Контроль виконання кредитного нормативу** — перевірка накопичення 240 кредитів за 4 роки і мінімуму 57–60 кредитів на рік; попередження при виборі низького навантаження, що збільшить навантаження в наступні роки.
7. **Адміністрування парсингу САЗ** — адміністратор вручну запускає оновлення каталогу; нові та оновлені дисципліни потрапляють у чергу модерації перед публікацією.

## Міні-ТЗ

### 1. Призначення системи

YourPathUkma розв'язує проблему хаотичного планування навчання для студентів Факультету інформатики НаУКМА, яке зараз ведеться вручну або в таблицях. Платформа дає кожному студенту єдине місце для побудови, порівняння та збереження річних планів вибіркових дисциплін — із повною видимістю кредитного навантаження, перевіркою конфліктів із нормативними дисциплінами та персоналізованими AI-рекомендаціями — щоб студент робив усвідомлений вибір до відкриття вікна запису.

### 2. Межі системи

**Входить у обсяг цього семестру:**
- Автентифікація студента через корпоративний Google SSO НаУКМА
- Особистий кабінет: історія планів, лічильники кредитів
- Конструктор плану: вибір вибіркових дисциплін по триместрах, рівні навантаження, перевірка конфліктів із нормативними дисциплінами із завантаженого документа деканату
- Каталог дисциплін, що наповнюється через парсинг САЗ адміністратором
- AI-генерація плану та альтернативних варіантів (лише на основі власної історії студента)
- Парсинг та пропозиція сертифікатних програм
- Збереження плану та автосинхронізація з САЗ (кнопка «Оновити»)
- Адмін-панель: запуск парсингу САЗ, керування довідниками

**Поза обсягом:**
- Подання заявки на запис у САЗ (платформа допомагає спланувати, а не записатись)
- Відгуки та рейтинги дисциплін або викладачів (лише посилання на зовнішню платформу)
- Комунікаційні функції (повідомлення, сповіщення)
- Мобільні нативні застосунки
- Підтримка факультетів, окрім Факультету інформатики
- Адмін-панель деканату або workflow затвердження плану всередині платформи

### 3. Ролі користувачів та їхні дії

| Роль | Що може робити |
|---|---|
| **Студент** | Вхід через SSO; перегляд кабінету та попередніх планів; завантаження документа деканату; налаштування побажань (до 3 напрямків, рівень навантаження на триместр, бажані/небажані викладачі, зацікавленість у сертифікаті); генерація, збереження та порівняння планів; отримання AI-рекомендацій |
| **Адміністратор** | Запуск парсингу каталогу CAЗ; перегляд та публікація черги модерації; керування напрямками та довідником сертифікатних програм |

### 4. Ключові функції

1. **Автентифікація через SSO** — вхід через корпоративний Google Workspace НаУКМА.
2. **Особистий кабінет** — історія планів за всі роки навчання, лічильники кредитів (загальні / вільного вибору / профорієнтовні), кнопка синхронізації з САЗ.
3. **Конструктор плану** — вибір вибіркових дисциплін по триместрах із рівнями навантаження (низьке/середнє/високе), завантаження документа деканату, перевірка конфліктів, контроль лімітів кредитів.
4. **AI-генерація плану** — рекомендаційний рушій на основі LLM: каталог дисциплін, напрямки студента, побажання та його власна історія планів; повний план із поясненнями та 2–3 альтернативи.
5. **Інтеграція сертифікатних програм** — автоматичний парсинг та звірка; пропозиція сертифікатних треків або окремих дисциплін.
6. **Каталог дисциплін** — джерело даних: САЗ; управляється адміністратором; фільтрація; контроль ліміту 25 кредитів вільного вибору.
7. **Контроль кредитного нормативу** — перевірка 240 кредитів загалом, мінімум 57–60 на рік, попередження при низькому навантаженні.

### 5. Нефункціональні вимоги

| № | Вимога | Метрика |
|---|---|---|
| НФВ-1 | **Продуктивність** | Сторінка каталогу дисциплін (з застосованими фільтрами) відповідає за 500 мс для 100 одночасних користувачів при нормальному навантаженні. |
| НФВ-2 | **Час відповіді AI** | Ендпоінт генерації плану повертає повний план протягом 15 секунд для 95% запитів. |
| НФВ-3 | **Безпека та приватність** | Тільки автентифікований студент може читати або змінювати свої плани та персональні дані; всі API-ендпоінти вимагають дійсний OAuth2-токен сесії; персональні дані студента не передаються в LLM — лише анонімізовані записи каталогу та агрегована власна історія планів. |
| НФВ-4 | **Надійність** | Збої парсингу САЗ не повинні впливати на доступність платформи; каталог залишається доступним для читання з останньої успішної синхронізації, а адміністратор отримує повідомлення про помилки парсингу протягом 5 хвилин. |

### 6. Припущення та обмеження

- **Стек:** React + TypeScript + Tailwind CSS (фронтенд); Python / FastAPI (бекенд); PostgreSQL; Docker; GitHub Actions CI/CD.
- **Автентифікація:** Google Workspace SSO НаУКМА доступний через OAuth2.
- **Доступ до САЗ:** система університету доступна для скрейпінгу (BeautifulSoup/Scrapy або Playwright для JS-сторінок); офіційного API не передбачається.
- **AI-модуль:** доступний API LLM; модель отримує лише дані каталогу та власну історію планів студента, що робить запит — дані інших студентів не використовуються.
- **Ресурс команди:** 4 студенти × ~7 годин/тиждень × 11 тижнів ≈ 308 годин загалом.
- **Плани 1-го курсу:** платформа не обслуговує планування 1-го курсу (тільки деканат); конструктор доступний з 2-го курсу.
- **Запис на дисципліни:** платформа формує план для орієнтації студента; фактичний запис відбувається зовнішньо в САЗ.
