# Річні кредити й тижневе навантаження (#291)

## Джерела й одиниці

ECTS — кредити за навчальну роботу; вони не дорівнюють контактним годинам на тиждень.
САЗ уже показує `год./тижд.` у картці каталогу. Парсер читає видимий текст
семестрового рядка, включно з дробами й нулем, а не HTML-атрибут `title`.
Додаткового обходу сторінок окремих дисциплін не потрібно. Тривалість навчальних
періодів не використовується для вигаданого перерахунку кредитів у години.

Поле `semesters[].weekly_hours` проходить через сканування, JSON-bundle v1,
порівняння, модерацію і `courses.semesters` (JSON, міграція 0008). Старі bundle
без годин приймаються. Старі дисципліни отримують `[]`, а не припущення про години.
Щоб заповнити їх, адміністратор повторює синхронізацію й схвалює пропозиції.
Дані каталогу змінюються лише після модерації. API каталогу повертає `semesters`.

## Спільна перевірка

`src/services/plan_workload.py` використовується в `/plans/validate`, під час
подання й після відповіді ШІ. Усі запити обмежені поточним студентом і навчальним роком.

Річний підсумок включає вибіркові, нормативні з останнього успішно розпізнаного
документа деканату й академічну історію цього року. Одна дисципліна в одному
триместрі рахується один раз, навіть якщо повторюється в кількох джерелах.
Для старого запису без ID зіставляється нормалізована назва, лише якщо вона має
один відомий ID. Неоднозначні однойменні дисципліни не зливаються.
Історичні копії нормативних із замінених документів не додаються до поточного документа.

Для кожного триместру додаються контактні години всіх цих дисциплін.
Нормативна дисципліна отримує години зі зв'язаного курсу каталогу для відповідного
триместру. Невідоме чи неоднозначне значення не замінюється нулем.

| Умова | Результат |
| --- | --- |
| Менше 20 год/тиждень | `low` |
| Від 20 до менш ніж 23 | `medium` |
| Від 23 до 25 включно | `high` |
| Більше 25 | `WEEKLY_LOAD_EXCEEDED` |
| Менше 57 ECTS за рік | `YEAR_CREDITS_BELOW_MIN`, попередження |
| Вибрано `low` і річний підсумок ≥57 | `LOW_LOAD_FUTURE_INCREASE`, попередження |

60 ECTS — цільовий орієнтир, не річна верхня межа.

Відсутність годин або розпізнаного документа дає `WORKLOAD_DATA_INCOMPLETE`,
`workload_complete: false` і `valid: false`. `workload_by_trimester` містить
відомий підсумок, повноту, відсутні дисципліни й фактичний рівень (або `null`).
Перевищення відомих годин виявляється навіть за неповних даних.

## Збереження й подання

Чернетку можна зберегти за перевищення годин або неповних даних. Подання блокує
підтверджене перевищення 25 годин. Річний мінімум і неповнота даних залишаються
попередженнями; UI явно попереджає про неповну перевірку перед поданням.
Чинні перевірки каталогу, вільного вибору, 240 кредитів, онбордингу та блокування
рядків зберігаються. Резервування кредитів іншими чернетками не змінювалося.

Для 4 курсу розподіл залишку ECTS не класифікується як години. Під час збереження
ручної або ШІ-чернетки рівні обчислюються з фактичних годин. Якщо годин бракує,
наявне обов'язкове поле рівня тимчасово зберігає `medium`; це не підтвердження
повноти, яку API повертає окремо. Побажання пояснюють цю неповноту.
