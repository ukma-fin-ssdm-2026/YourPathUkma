# Звіт покриття тестами

> **Звіт згенеровано автоматично** інструментом `coverage.py` (через `pytest-cov`). Файли `*.html`, `*.js`, `*.css` у цій теці не редагуйте вручну: після змін у коді чи тестах перегенеруйте звіт командою нижче.

HTML-звіт покриття коду `src/` (рядки та гілки). Щоб переглянути, відкрийте `index.html` у браузері.

**Дата запуску:** 2026-10-21  
**Команда:**

```bash
python -m pytest -q --cov=src --cov-branch --cov-report=html:docs/testing/coverage
rm docs/testing/coverage/.gitignore   # coverage.py сам створює цей файл, і він ховав би звіт від git
```

Усі файли в цій теці, крім цього README, згенерував `coverage.py`, вручну їх не редагували.
