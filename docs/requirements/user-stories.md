# User Stories
**Формат:** `Як <роль>, я хочу <можливість>, щоб <вигода>.`
- **Як** користувач, **я хочу** отримати персоналізований план розвитку на основі моїх інтересів, **щоб** оптимізувати свій навчальний план на наступний рік.
- **Як** користувач, **я хочу** зберігати згенеровані персоналізовані плани, **щоб** мати змогу переглядати їх у майбутньому та обирати з них найбільш підходящий.
- **Як** користувач, **я хочу** фільтрувати дисципліни за викладачами, **щоб** уникати вибору тих викладачів, чий підхід до викладання мені не подобається.
- **Як** користувач, **я хочу** вказувати декілька напрямів розвитку під час створення плану, **щоб** отримати максимально точний персоналізований план, який відповідає всім моїм потребам.
- **Як** адміністратор, **я хочу** автоматично завантажувати всі актуальні дисципліни з каталогу САЗ, **щоб** уникнути необхідності додавати кожну дисципліну вручну.
- **Як** користувач, **я хочу** отримувати альтернативні варіанти плану навчання, **щоб** мати запасні дисципліни без втрати якості навчання у разі, якщо не вдасться записатися на основні курси.
