# User Stories
**Формат:** `Як <роль>, я хочу <можливість>, щоб <вигода>.`
- **Як** студент, **я хочу** обирати бажаний рівень навантаження (високе, середнє, низьке) окремо для кожного триместру, **щоб** згенерований план розподіляв кредити відповідно до моїх можливостей протягом року.
- **Як** студент, **я хочу** зберігати згенеровані персоналізовані плани, **щоб** мати змогу переглядати їх у майбутньому та обирати з них найбільш підходящий.
- **Як** студент, **я хочу** фільтрувати дисципліни за викладачами, **щоб** уникати вибору тих викладачів, чий підхід до викладання мені не подобається.
- **Як** студент, **я хочу** мати можливість вказувати до 3 напрямів розвитку під час створення плану, **щоб** отримати максимально точний персоналізований план, який відповідає всім моїм потребам.
- **Як** адміністратор, **я хочу** ініціювати парсинг всіх актуальних дисциплін з каталогу САЗ, **щоб** уникнути необхідності додавати кожну дисципліну вручну.
- **Як** студент, **я хочу** отримувати альтернативні варіанти плану навчання, **щоб** мати запасні дисципліни без втрати якості навчання у разі, якщо не вдасться записатися на основні курси.
