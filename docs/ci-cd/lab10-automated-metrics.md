# Бонус №1 — автоматичний підрахунок метрик

Запустіть команду з кореня репозиторію, використовуючи Python 3.12 та авторизований GitHub CLI.

```sh
python scripts/ci_metrics.py --repo ukma-fin-ssdm-2026/YourPathUkma --workflow ci.yaml --from 2026-10-23T00:00:00Z --to 2026-11-13T00:00:00Z --output docs/ci-cd/lab10-automated-metrics.json
```

Для виводу JSON у термінал передайте `--output -`. Цей режим також підходить для перенаправлення звіту в інший файл.

Підрахунок охоплює завершені запуски після push у `main`, створені в заданому вікні UTC з виключеною верхньою межею. Перша версія ручного звіту вимірювала час виконання змін для 80 зелених запусків із PR. Скрипт додає ще вісім зелених запусків прямих комітів і починає відлік для них з часу авторства коміту. У JSON наведено всі чотири метрики, тривалості в секундах і частки черги та виконання.
