# Шрифти для генерації PDF

Шрифти DejaVu Sans та DejaVu Sans Bold використано для підтримки кириличних символів (української мови) при серверній генерації PDF навчального плану.

- Джерело: DejaVu Fonts project (https://dejavu-fonts.github.io/)
- Ліцензія: Bitstream Vera Fonts License / Arev Fonts License / Public Domain (вільне використання та поширення).

## Використання ШІ

Файли шрифтів DejaVu завантажено та налаштовано за допомогою Antigravity (Gemini 2.5 Pro, Google DeepMind) для задачі #296. Перевірено тестами fpdf2 та pytest.
